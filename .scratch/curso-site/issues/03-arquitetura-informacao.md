# Arquitetura de informação: o que é "estudo", "consulta", "exercício" e "slides", e como se navega
Type: grilling
Status: resolved
Blocked by: —

## Question

Definir o modelo de conteúdo: por encontro (estudo / exercícios / slides) e transversal (consulta: método C-O-R-R-F, glossário, biblioteca de ferramentas, biblioteca de +30 prompts, modelo de base de conhecimento, frameworks). Como os 4 itens do Kit da landing se mapeiam para páginas? Navegação, ordem (antes/durante/depois da aula), página inicial do site.

## Answer

- Navegação por encontro (E1–E4: Estudo · Exercícios · Slides) + seção transversal **Consulta**.
- Estudo = revisão/aprofundamento pós-aula, com caixa "Antes da aula (5 min)" no topo.
- **Conceitos são o núcleo**: cada conceito é uma página na Consulta com anatomia fixa (definição em 1 frase · analogia · diagrama à mão · na prática · erro comum · teste rápido de 1 min). Encontros apontam para os conceitos, sem duplicar.
- Lista de conceitos: E1 modelo de linguagem, token, janela de contexto, custo e limites, modelos diferentes, raciocínio, alucinação, C-O-R-R-F · E2 contexto, instruções fixas (Projetos), fontes e referências, Gemini Notebook · E3 revisão de texto, análise de planilha, deep research, checagem de fontes (páginas mais curtas) · E4 base de conhecimento, processo → rotina, formato aberto (OKF).
- Consulta também: cartão C-O-R-R-F, glossário, ferramentas grátis × pago, modelo de base de conhecimento, frameworks. Sem biblioteca de prompts autoral; o índice "+30 prompts" é gerado automaticamente dos exercícios.
- Exercícios: página separada por encontro (usada ao vivo).
- Publicação: cada encontro na véspera da aula.
- Home "Comece aqui": próximo encontro, progresso local, atalhos para a Consulta.
- PDF: slides de cada encontro (reveal ?print-pdf) na véspera + Kit completo após E4, gerado das páginas do site.
