# Formato do exercício prático
Type: grilling
Status: resolved
Blocked by: 03

## Question

Anatomia de um exercício: objetivo, situação real, prompt (com as partes C-O-R-R-F destacadas), caminho grátis vs. pago, critério "deu certo se…" verificável, armadilhas comuns, variações. Como o progresso aparece? Exercício em aula vs. de casa? Um exemplo completo aprovado vira o template.

## Answer

Anatomia (nesta ordem): título + duração + etiqueta grátis · situação real · pedido em 5 partes (Contexto, Objetivo, Referências, Restrições, Formato), copiável, com `[campos]` para trocar · "deu certo se…" (3 itens verificáveis, marcáveis) · "não deu certo?" (provável motivo + link para o conceito a reler) · desafio extra · link para o conceito.
- Grátis é o padrão; caixa "No plano pago" só quando muda algo.
- Dados: exemplo pronto para baixar + convite "agora tente com o seu".
- Marcação "em aula" (2–3 por encontro) ou "para casa" (1–2).
- Campo curto "o que mudou na resposta?" (reflexão), salvo só no navegador; nada de colar resposta inteira.
- Comparação pedido curto × completo: padrão só no E1; nos demais, desafio opcional.
- Nome do método: a sigla C-O-R-R-F não pega (nem o João lembrou); proposta "o pedido em 5 partes", aguardando confirmação.
