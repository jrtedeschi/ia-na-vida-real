## O que fazer

1. **Use um computador.** O editor do Apps Script não funciona direito no celular, e o app Planilhas do celular não mostra menus criados por script. O celular entra só no passo 06.
2. **Uma conta só.** Se você usa mais de uma conta Google no mesmo navegador, o Apps Script costuma se confundir. Abra uma janela anônima (Ctrl+Shift+N no Chrome) e entre só com a conta que vai usar.
3. **Conta pessoal ou do trabalho/escola?** Contas pessoais (@gmail.com) funcionam. Contas de empresa ou escola (Google Workspace) podem ter o Apps Script bloqueado pelo administrador. Se for o caso, use uma conta pessoal para aprender.
4. **Trabalhe numa planilha nova.** Não use uma planilha que já tem dados importantes. Se quiser reaproveitar uma depois, faça antes uma cópia: menu **Arquivo**, **Fazer uma cópia**.
5. **Privacidade.** A planilha vai ter seus gastos reais. Ela fica só na sua conta. Na conversa com a IA, nunca cole CPF, número de conta, cartão ou senhas. Para pedir ajuda, cole só a mensagem de erro.

## Erros comuns

- Tela "Desculpe, não foi possível abrir o arquivo no momento" (em inglês: "Sorry, unable to open the file at this time."): quase sempre é mais de uma conta conectada. Use a janela anônima com uma conta só.

## Condição de parada

Se a pessoa só tem celular, pare aqui e explique que precisa de um computador para os passos 01 a 05.
