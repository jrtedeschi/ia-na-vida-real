
- **Apps Script**: linguagem do Google para automatizar Planilhas, Gmail e Drive. É JavaScript que roda nos servidores do Google.
- **Script vinculado**: código que mora dentro de uma planilha (aberto por Extensões, Apps Script). Pode criar menus nela.
- **Manifesto (appsscript.json)**: arquivo de configuração do projeto: fuso horário e versão do motor (V8).
- **Permissões (escopos)**: o que o app pode fazer na sua conta. Aparecem na tela de autorização.
- **Gatilho (acionador)**: regra que faz uma função rodar sozinha, por exemplo toda segunda às 8h.
- **Execuções**: tela do editor que mostra cada vez que o código rodou e os erros.
- **Localidade**: configuração da planilha que define como números e datas são lidos (Brasil: 45,90 e dd/mm/aaaa).
- **App da Web (web app)**: página publicada pelo seu script, acessada por um link `/exec`.
- **Implantação (deploy)**: publicar uma versão do web app.
